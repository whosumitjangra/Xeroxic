About Xerox Centre

🎓 Campus Technology ⚡ High Performance Cloud Stack

Smart Campus Xerox Management System

Built with precision and love — Made by Antigravity with Sumit for Army Institute of Technology (AIT), Pune. Empowering students, faculty, and shop administrators with zero-queue smart printing.

System Architecture & Technology Stack

A comprehensive look under the hood at the enterprise-grade database, storage, serverless APIs, and security powering Xeroxic v3.0.0:

🍃
MongoDB Atlas Cloud DB

High-performance distributed MongoDB Atlas cluster with cached connection pooling, atomic transactions, partitioned daily counters, and rolling 10-order student history.

MongoDB Atlas Mongoose ODM Connection Pooling
⚡
Node.js Serverless APIs

Scalable Vercel Serverless Node.js functions delivering sub-50ms RESTful endpoints for order submissions, assignment retrieval, and payment processing.

Node.js Vercel Serverless Sub-50ms Cold Starts
☁️
Supabase 50MB Cloud Storage

Pre-authenticated signed URL architecture streaming files up to 50MB directly to Supabase Storage, completely bypassing Vercel 4.5MB serverless RAM limits.

Supabase Storage Signed Direct URLs 50MB File Ceiling
🎫
Express QR Pass & Memorable IDs

Human-memorable Order IDs (e.g. sumit24001, ali##24001) with automatic hash padding, paired with a glowing ⚡ Express QR Pickup Pass for 5-second counter handoffs.

Memorable IDs Vector QR Matrix # Hash Padding
⏱️
0ms Instant Status Synchronization

Optimistic state transitions allow operator status changes (QUEUED → PRINTING → READY) to render with 0ms visual delay, with automatic student polling suspension upon completion.

0ms Instant Sync Optimistic UI Battery-Safe Polling
🛡️
Auto-Purge Storage Reclaim

Zero-retention privacy engine that permanently deletes uploaded document payloads from Supabase cloud storage the instant an order is marked COLLECTED, protecting student data.

Auto-Purge Zero Data Retention Privacy First
👑
Super Admin & Monthly Archival

Multi-role RBAC with a centralized Super Admin directory to manage student accounts, toggle active status, and perform automated 30-day monthly print ledger renewals.

Super Admin RBAC Student Directory Monthly Archiving
💳
Razorpay UPI & HMAC Verification

Tamper-proof payment gateway with server-side HMAC-SHA256 signature verification ensuring orders are only admitted to the print queue once payment is cryptographically verified.

Razorpay Standard HMAC-SHA256 UPI / QR Codes
